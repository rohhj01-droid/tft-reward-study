### 3-1. 10.20이 패치 분기에서 빠졌다 (`6883d4a`)

10.20을 나중에 추가하면서(커밋 4138503) 코드 안 패치 분기의 "옛 패치" 목록에는 10.20을 넣지 않았다.

| 리 신 | 10.23 | 3성이 대상 주변 적까지 경기장 밖으로 날렸다 |

of shields"가 있다. 둘 다 10.22부터라서 10.20에 걸리던 코드를 특성 수정 때 고쳤다(`a39f1ee`, `5918312`).
이제 코드에 패치 이름을 나열하는 분기가 하나도 없다.

### 3-2. 워윅 (`d2feeac`)

포크가 넣은 두 효과 모두 대기열 함수의 두 번째 인자(몇 ms 뒤 실행)를 지속 시간으로 잘못 썼다.

- 10.20~10.23 공포 근사: 시전 1.5초 뒤(10.23은 0.75초 뒤) 대상이 기절하고 끝까지 안 풀렸다. 10.20 시전 19번 중 18번이 전투 끝까지 기절이었다.
- 10.24 울부짖음: 아군 공속이 3초 뒤에 오르고 안 내려갔다. +60% 대신 초당 1.6회를 그대로 더해 평균 +1.62였고, 특성 공유와 상관없이 모든 아군에게 걸렸다.

실제대로 궁을 쓴 뒤 처치할 때 발동하게 바꿨다. 기절은 처치 즉시 걸려 1.5초(10.23 0.75초) 뒤 풀리고,
울부짖음은 특성을 공유하는 아군 공속을 즉시 1.6/1.75/3.0배로 올렸다가 3초 뒤 되돌린다. 한 순간에 처치가 여러 번 나도
겹쳐 곱하지 않고 끝나는 시간만 갱신한다. 막타만 세고 도움은 아직 안 센다.

### 3-4. 아펠리오스 포탑 (`804456b`)

- 10.23 전에는 포탑 공격이 아펠리오스 마나를 채웠다(10.23 노트: Turret no longer grants mana). 시뮬레이터는 쇼진 몫만 넘겼다. 지금은 공격당 마나도 넘긴다. 발사당 본체 마나가 +0에서 +6~7이 됐다.
- 10.21부터 아펠리오스가 기절하면 포탑도 멈춘다. 구현이 없었다. 본체를 일부러 기절시킨 발사 시도에서 10.20은 12번 모두 쐈고, 10.21~10.24는 147번 모두 멈췄다.
- 아직 안 한 것: 10.23 전 포탑 공격이 본체 아이템의 공격 시 효과(구인수의 격노검 등)를 발동하는 것.

## 4. 맞는 것

- 코스트 58종이 위키와 같다.
- 기본 스탯 8개(체력, 공격력, 공속, 방어력, 마저, 시작 마나, 최대 마나, 사거리)를 58종 × 5패치로 봤다. 2번 항목 말고는 같다.
- 공식 노트의 챔피언 수치 변경(A ⇒ B)이 전부 시뮬레이터에 들어가 있다.
- 선택받은 자 보너스 종류가 패치별로 맞다. 피오라·바이·세트는 10.22, 징크스는 10.24에 바뀐다.
- 상점 확률 레벨 5~8, 선택받은 자 확률, 레벨업 경험치가 10.19·10.20·10.24 노트와 같다. 레벨 3·4·9 상점 확률은 노트에 없어서 확인하지 못했다.

## 5. 이 대조로 못 잡는 것

- 스킬 값은 그 챔피언의 어느 표에든 같은 숫자가 있으면 일치로 본다. 다른 표의 같은 숫자에 걸리면 놓친다. 리븐(베기와 보호막이 175/250/750로 같다), 케인, 리 신이 그렇게 숨어 있었다.
- 그래서 같은 변경이 패치마다 다른 표에서 잡히면 `TABLE_SHIFT`로 표시하게 했다. 세 항목은 이 검사로 드러났다. 모든 패치에서 같은 다른 표에 걸리는 경우는 여전히 못 잡는다.
- 노트에 한 번도 안 나온 값은 위키 하나로만 봤다.

## 6. 아직 안 본 것

- 스킬 58개의 코드를 설명과 하나씩 대조하지는 않았다. 3번은 패치 분기와 일부 스킬만 읽고 찾은 것이다.
- 아이템, 스테이지 피해. 스테이지 피해표(`game_round.py:16`)는 패치와 상관없이 하나인데, 10.24 노트에서 이 표가 바뀌었다(0/0/1/2/5/10/15 ⇒ 0/0/2/3/5/8/15). 특성은 아래에 따로 정리했다.
- 공속 증가가 곱인지 합인지가 챔피언마다 다르다. 워윅 본인 궁만 공속에 더하고, 나머지는 곱한다.

## 결과 파일 읽는 법

`mismatch_set4.csv`의 `status` 열이다.

| status | 뜻 |
|---|---|
| MISMATCH | 기본 스탯이 다르다 |
| NOT_FOUND | 출처의 스킬 값이 시뮬레이터 표 어디에도 없다 |
| TABLE_SHIFT | 같은 변경이 패치마다 다른 표에서 잡혔다. 우연히 같은 숫자에 걸렸을 수 있다 |
| UNRESOLVED | 위키 이력의 "A에서 B로"에서 A를 못 찾았다 |
| KNOWN | 출처 쪽 오류나 도구 한계로 확인이 끝났다. 이유는 `note` 열과 `diff_set4.py`의 `KNOWN`에 있다 |
| REVIEW | 숫자가 아닌 변경이라 사람이 봐야 한다 |

지금 열린 줄(MISMATCH, NOT_FOUND)은 2번의 네 항목뿐이다.

패치 이력으로 봤다. 위키의 Set 4 특성 설명은 세트 마지막 값과 옛 값이 섞여 있어서 그대로 쓰지 않았다.

## 4. 근거 없이 들어간 것과 근사 (고치지 않음)

- 결투가가 이동 속도 20% 증가를 받는다(`origin_class.py`의 duelist). Set 4 설명과 패치 이력 어디에도 없다.
- 명사수 튕김 대상이 무작위다. 실제는 가까운 적이다.
- 총사령관 승리 보너스를 지금 연승 수로 센다(`game_round.py`). 위키는 "참여한 승리마다, 최대 5번"이라 패배로 끊기지 않는다.
- 행운 보상을 골드로 환산해 바로 준다. 표를 넘는 연패는 마지막 값에 한 번에 15골드씩 더하는데 근거가 없다.
- 행운 10~12연패 보상 90/115/145골드는 공식 10.23이 "표를 추가했다"고만 해서 값을 확인하지 못했다.
- 결투가가 죽어 단계가 내려가면 실제는 기존 중첩도 낮은 값으로 다시 계산된다. 여기서는 이후 중첩에만 새 값이 들어간다.

## 5. 특성 밖에서 같이 고친 것

패치를 적용하는 곳은 MuZero 학습 워커뿐이라, 전체 게임 스크립트·전투 도구·분석은 기본값으로 돈다.
챔피언·특성 기본값은 10.24인데 상점 확률(레벨 5~8)과 선택받은 자 확률은 어떤 실제 패치와도 맞지 않았다.
예를 들어 레벨 6이 25/40/30/5였다(실제 10.24는 35/35/25/5). 10.24 공식 값으로 맞췄다(`3bc6f6c`).
1학기 전체 게임 기준선은 옛 확률로 나온 값이고, tft-reward-study의 `set4.py`도 옛 확률을 옮겨 썼다.
`set4.py`도 같은 10.24 값으로 맞췄다(curt-2 `124d8c2`). 그래서 `results/README.md`의 1학기 숫자는 옛 확률로 잰 값이다.
시드를 고정해 같은 조건에서 재 보면 slow-roll 기준선이 35.7에서 34.7로 내려간다. 1코스트 리롤 비용은 레벨 6, 7에서 싸진다(레벨 6 2성 66골드에서 47골드로).
